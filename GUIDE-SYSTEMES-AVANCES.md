## SYSTEME DES DERIVES DU COTON

### Vue d'Ensemble

Le coton n'est pas qu'une fibre textile ! Dans Tycoon, vous decouvrez toute la chaine de valeur :

```
COTON BRUT (100kg)
    ↓
EGRENAGE
    ├─→ FIBRE (35kg) ─→ TEXTILE (28m)
    └─→ GRAINES (60kg)
            ↓
        TRITURATION
            ├─→ HUILE (15L)
            └─→ TOURTEAUX (80kg)
```

### Les 5 Derives

1. **GRAINES DE COTON**
   - Valeur : 50 FCFA/kg
   - Debloque : Niveau 3
   - Usage : Transformation en huile

2. **FIBRE DE COTON**
   - Valeur : 200 FCFA/kg
   - Debloque : Niveau 3
   - Usage : Textile ou exportation

3. **HUILE DE COTON**
   - Valeur : 800 FCFA/L
   - Debloque : Niveau 4
   - Usage : Consommation locale ou export

4. **TOURTEAUX**
   - Valeur : 150 FCFA/kg
   - Debloque : Niveau 4
   - Usage : Aliment pour betail

5. **TEXTILE MADE IN BENIN**
   - Valeur : 2000 FCFA/m
   - Debloque : Niveau 5
   - Usage : Exportation premium

### Ratios de Transformation

**Egrenage (Niveau 3+):**
- 100kg coton → 35kg fibre + 60kg graines

**Trituration (Niveau 4+):**
- 100kg graines → 15L huile + 80kg tourteaux

**Filature (Niveau 5+):**
- 1kg fibre → 0.8m textile

### Strategie de Maximisation

Pour 1000 FCFA de coton brut :

**Option 1 : Vente Directe**
- Gain : 1000 FCFA

**Option 2 : Transformation Complete**
- Fibre → Textile : 28m × 2000 = 56,000 FCFA
- Graines → Huile : 15L × 800 = 12,000 FCFA
- Tourteaux : 80kg × 150 = 12,000 FCFA
- **Total : 80,000 FCFA (×80 !)**

## SYSTEME D'EXPORTATION

### Deblocage

- **Niveau 5 :** Acces a l'Afrique
- **Niveau 6 :** Acces a l'Asie et l'Europe

### Les 3 Destinations

#### 1. AFRIQUE
**Pays :** Nigeria, Ghana, Togo
- Prix : ×1.2
- Transport : 5 jours
- Debloque : Niveau 5

#### 2. ASIE
**Pays :** Chine, Bangladesh, Vietnam
- Prix : ×1.5
- Transport : 30 jours
- Debloque : Niveau 6

#### 3. EUROPE
**Pays :** France, Allemagne, Italie
- Prix : ×1.8
- Transport : 20 jours
- Debloque : Niveau 6

### Bonus du Terminal Portuaire

Chaque niveau du terminal ajoute +15% au prix d'exportation :

- Niveau 1 : ×1.15
- Niveau 2 : ×1.30
- Niveau 3 : ×1.45

**Exemple :**
- Textile de base : 2000 FCFA/m
- Vers Europe : 2000 × 1.8 = 3600 FCFA/m
- Avec Terminal Niv.3 : 3600 × 1.45 = **5220 FCFA/m**

### Strategie d'Exportation

**Court Terme (Afrique) :**
- Transport rapide (5j)
- Rotation rapide du capital
- Bon pour le cash-flow

**Long Terme (Europe) :**
- Meilleurs prix
- Temps de transport raisonnable
- Equilibre ideal

**Ultra-Rentable (Asie) :**
- Volume massif
- Temps long mais tres rentable
- Pour stocks importants

## GESTION DES COUTS

### Maintenance des Batiments

Chaque batiment coute en maintenance :

```
Total/heure = Σ (cout_base × niveau)
```

**Exemple avec tous les batiments niveau 1 :**
- Egrenage : 50 FCFA/h
- Trituration : 100 FCFA/h
- Filature : 150 FCFA/h
- Entrepot : 20 FCFA/h
- Terminal : 500 FCFA/h
- **Total : 820 FCFA/h**

### Break-Even Point

Votre production doit couvrir la maintenance :

```
Production minimum = Maintenance / Prix moyen
```

Si maintenance = 820 FCFA/h et prix textile = 2000 FCFA/m :

```
Production min = 820 / 2000 = 0.41m/h
```

Facile a atteindre avec la filature niveau 1 (30m/h) !
